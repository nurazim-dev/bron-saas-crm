# BRON Phase 2 — состав визита, 17.11.2026

Выполнен следующий инкремент Core Booking; вся Phase 2 не закрыта.

## Реализовано

- До 10 разных услуг подряд у одного мастера, до 720 минут и 1 000 000 KGS.
- Общая цена и предоплата online-визита рассчитываются Decimal на сервере.
- Availability и повторная проверка внутри транзакции охватывают весь интервал.
- ANY выбирает только мастеров всех услуг, сохраняя блокировку одного кандидата.
- AppointmentService: снимки названия, каталожной цены, длительности и порядка;
  составные внешние ключи запрещают связи между компаниями на уровне PostgreSQL.
- Старые serviceId/API сохранены; одиночные клиенты продолжают работать.
- Staff create/edit, public RU/KY selection, подтверждение, перенос по manage-link,
  CRM-история, календарный фильтр и напоминания поддерживают состав визита.
- Аналитика учитывает каждую услугу с распределением итоговой цены без потери тыйынов.
- Данные контактов сохраняются при возврате назад; длинные названия переносятся.

## Ограничения

- Пока один мастер на весь визит; разные мастера по частям визита не поддерживаются.
- Предоплата существующего визита при смене состава автоматически не пересчитывается.
- Старые названия услуг при backfill восстановлены из текущего каталога, поскольку
  прежняя схема исторические названия не сохраняла; новые снимки неизменны при переносе.
- Новые статусы, пакеты, цены мастеров, drag-and-drop и оставшаяся Foundation впереди.
- Полный E2E-набор не запускался; pg concurrent-query и NO_COLOR warnings сохраняются.
- Phase 3 и deployment не начинались.
