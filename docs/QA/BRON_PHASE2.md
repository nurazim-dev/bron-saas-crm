# BRON Phase 2 — календарь и управление записью

Статус: календарный инкремент выполнен; полная Phase 2 остаётся открытой.
Пользователь явно разрешил Phase 2 при незавершённой Foundation.

## Реализовано

- День, неделя с понедельника, месяц с соседними днями до полной недели.
- Переходы по периодам, переход из периода в день, выбор даты и услуги.
- Читаемый список дня на телефоне; недельный список и месячная сетка на desktop.
- Все страницы записей периода вместо прежних первых 200; отмена устаревших
  запросов при смене периода, стабильный tie-breaker id в backend-сортировке.
- Дневная сетка расширяется за 08:00–22:00 по часам работы/записям.
- Карточка и форма используют существующий Radix Dialog: Escape, focus trap.
- Бизнес-статусы, tenant isolation, транзакционные блокировки и EXCLUDE сохранены.
- Новых зависимостей и миграций нет; предыдущие изменения сохранены.
