правки из рабочего дерева не установлена; история Git её не содержит.

один прошёл. Лог сохранён в artifacts/repair-qa001/before.log.

Убран лишний аргумент; после проверки блокировки клиента внутри той же транзакции
публичной записи выполняется update языка с фильтром id + companyId. Значение:
locale запроса либо defaultLocale компании. Staff upsert остаётся без изменений.
Не менялись блокировки мастеров, ограничения слотов, токены и уведомления.

Сохранены исходный diff и копия public.service.ts. Изменения других фаз не откатывались.
Нет миграций, новых зависимостей и изменений frontend.
