# U1 — визуальное направление

17.11.2026. Новый редакционный дизайн главной: разделённый первый экран,
крупная типографика с засечками в акценте, фотография интерьера, последовательная
история возможностей и записи, реальные тарифы API, завершающий CTA и footer.
Обновлены визуальная оболочка входа и навигация кабинета; active link имеет aria-current.
Бизнес-логика, API, auth и предыдущие изменения не заменялись.

## Движение

Reveal через IntersectionObserver + Web Animations API (280мс), без библиотеки,
контент не скрыт до гидратации. Hero photo: короткое появление/масштабирование
только на desktop. Меню: 220мс. При reduced motion эффекты отключаются;
для reveal проверяется системное предпочтение при монтировании.
Скролл не перехватывается. Скриншоты и запись браузера: artifacts/upgrade-u1/.

## Ограничения

В начале U1 в рабочем дереве уже отсутствовало исправление public.service.ts из U0.
Общий gate повторно упал с TS2353 locale. Исходный backend не перезаписывался;
браузер использует последнюю доступную backend dist-сборку U0 и тестовую БД.
Поэтому браузерная проверка интерфейса не подтверждает сборку текущего backend source.
Следующую фазу начинать с восстановления согласованного контракта QA-001.

Портфолио/загрузка медиа, перевод оставшихся строк публичной записи,
детальный редизайн рабочих страниц и полный security-аудит остаются U2–U5.
