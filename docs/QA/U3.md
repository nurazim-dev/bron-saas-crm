# U3 — редактор и публичный профиль

Реализованы owner-only страница портфолио, описание/специализации/опыт, загрузка
с прогрессом, превью, фото-замена, обложка, порядок и удаление. Карточка мастера
открывается без сброса состояния записи, видео грузится по действию пользователя.
Модальные окна используют установленный Radix для focus trap/restore и Escape.
Typecheck frontend — exit 0. Браузерная проверка войдёт в общий протокол U5.
