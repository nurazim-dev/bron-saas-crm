# U2–U5 — итоговый протокол, 17.11.2026

Фазы выполнены последовательно по прямому указанию пользователя. Исходные
незакоммиченные правки сохранены; снимок — `artifacts/upgrade-u2-u5/before.patch`.

## Что изменено

- U2: профиль мастера и tenant-scoped owner-only медиа API, безопасное декодирование,
  WebP/MP4, постеры, квоты, атомарная замена, удаление и очистка временных файлов.
- U3: редактор портфолио, биография/специализации/опыт, превью, обложка и порядок.
  Публичные работы/график мастера открываются без сброса выбора и формы записи.
- U4: основной путь записи и управления RU/KY, кыргызские дни недели и ошибки,
  календарь ICS в UTC, анимации шагов, touch 44 px, доступные модальные окна и меню.
- U5: Telegram companyId boundary, одноразовая привязка, дедупликация update_id,
  transactional outbox вместо синхронного ответа провайдера. Публичный DTO без PII.
- Исправлены CSP для видео-превью, главная без JavaScript, переполнение админки
  при 1024 px, ошибка API вместо ложного «нет слотов», зависание при повторе даты.
- Уязвимая транзитивная minimatch обновлена целевым override. `.env` исключены
  из Docker-контекста. Миграция применена к dev/test без сброса рабочей БД.

## Проверено

- Обычный `npm run gate`: typecheck, ESLint/Prettier, 163 теста / 34 файла,
  production build, guard — exit 0. `gate:full` не запускался: он сбрасывает dev-БД.
- Chromium: 110 сочетаний страниц и ширин 360/390/768/1024/1440,
  включая все разделы кабинета и 8 разделов админки; нет переполнения страницы.
- Owner upload → публичный профиль → KY booking → назад без потери формы → ICS
  → перенос → отмена. Видео действительно воспроизводится; клавиатурные меню,
  reduced motion, no-JS главная и короткий viewport формы проверены.
- 14 штатных Chromium E2E: регистрация, роли, гонка слота, reset через Mailpit,
  TOTP, impersonation, биллинг, CRM, отпуск, self-service, уведомления, KY и PWA.
- HTTP/DB: чужая компания 404, MASTER 403, JWT 401, скрытие PENDING и private fields,
  MIME spoofing, повреждённые/большие фото, EXIF, квота, cover, замена/удаление.
- Реальный MP4 обрабатывается локально и в production Docker под non-root,
  без сети, с лимитом памяти 512 MiB. Docker build — exit 0.
- Backup/restore в отдельную временную БД: совпали bytes двух медиа и восстановлено
  EXCLUDE-ограничение записи. Временная БД и dump удалены.
- Локальный API-прогон: 60 HTTP 200 при concurrency 8, p95 29.9 ms.
  Это не оценка пропускной способности production.
- npm audit (включая dev): 0 известных уязвимостей. Логи и скриншоты:
  `artifacts/upgrade-u2-u5/`.

## Ограничения

- pg DeprecationWarning concurrent client.query сохраняется через Prisma adapter
  даже после последовательного выполнения явных запросов транзакции; не подавлялся.
- CSP scripts всё ещё использует существующий unsafe-inline; nonce-переход не выполнен.
- Реальное подключение Telegram через пользовательский /start и клавиатура физического
  телефона не проверены. Использовались тестовая БД, Chromium и эмуляция touch.
- Privacy/terms остаются DRAFT. Полный внешний pentest и production-нагрузка не проводились.
- Медиа в PostgreSQL рассчитаны на небольшое портфолио; ограничения описаны в RUNBOOK.
