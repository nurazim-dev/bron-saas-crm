# Редизайн Zapis.kg

## Фаза R1 — основа и вход в продукт

Область: общие цветовые токены, фокус и уменьшение анимаций, главная страница,
переиспользуемая оболочка входа и регистрации. API, проверка форм, авторизация,
маршруты и прежние незакоммиченные изменения сохранены.

Стиль: фон `#f7f7f2`, текст `#252d29`, основной зелёный `#245c46`, белые поверхности,
вторичная поверхность `#eeefe8`. Базовое скругление 14 px; отступы кратны 4 px.
Существующий Inter с кириллицей. Основное движение 200–260 мс, без новых зависимостей.
На touch устройствах общие кнопки имеют минимальную область 44 × 44 px.

## Инвентаризация и следующие фазы

- R2: кабинет и onboarding. Общий DashboardShell, роли OWNER/MASTER, уведомления,
  read-only состояния подписки и impersonation. Настройки, профиль и оплата.
- R3: рабочие сценарии. Расписание, диалоги записей, услуги, сотрудники, список и
  карточка клиента, аналитика. Отдельная мобильная композиция таблиц и расписания.
- R4: публичный путь `/b/[slug]` и `/manage/[token]`. Существующий stepper хранит
  услугу, мастера, дату, контакты и согласие в React state; сохранить переходы назад.
  Проверить RU/KY, предоплату, выбор ANY, конфликты слотов, отмену и перенос.
- R5: AdminShell и административные страницы, затем сквозная регрессия всех ролей.

Общие токены уже влияют на все страницы; это не означает, что остальные страницы
прошли полный редизайн или визуальную приёмку. Известный риск публичного пути:
часть заголовков stepper обращается напрямую к `ru`, хотя переключатель языка существует.
Проверка и исправление относятся к R4.

## Проверки R1

Браузерный сценарий и снимки: `artifacts/redesign-phase1/`.
Матрица главной, входа и регистрации: 360, 390, 768, 1024, 1440 px.
Проверки: переполнение, ошибки JS/HTTP, валидация форм, настоящий вход demo OWNER,
переход в кабинет, ссылки главной, prefers-reduced-motion. Ожидаемый 401 при
восстановлении отсутствующей гостевой сессии не считается ошибкой приложения.
Регистрация новой компании, мобильная экранная клавиатура и RU/KY публичной записи
в R1 не проверяются. Никакие данные клиентов ради дизайна не изменяются.

Общие typecheck и lint блокируются прежними изменениями `clients.service.ts`:
отсутствует параметр locale, а форматирование не проходит Prettier. Файл сохранён.

### Итог выполненной проверки

- Chromium: 18 проверок завершились успешно, неожиданных HTTP-ошибок и исключений JS нет.
- Отдельно: успешный вход с touch viewport 390 px и видимый клавиатурный фокус.
- Скриншоты 15 вариантов получены на production-сборке; главная 360/1440,
  вход 390 и регистрация 1440 просмотрены визуально.
- `npm run build -w frontend`, `npm run typecheck -w frontend`,
  `npm run lint -w frontend`, `git diff --check`: exit 0.
- На массовом прогоне с обычным лимитом авторизации получен ожидаемый 429;
  успешный повтор выполнен с временным `RATE_LIMIT_AUTH_MAX=100` в тестовом процессе.
  Конфигурационные файлы и защитные правила не изменены.
- Все прежние изменённые и untracked файлы сверены по SHA-256 и сохранены побайтно.
- Полный редизайн не завершён: R2–R5 остаются отдельными фазами.
