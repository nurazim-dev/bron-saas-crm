## Dismissed Tool Scanner Alerts (False Positives / Accepted Architecture)

1. **`gitleaks dir` — `backend/.env` & `backend/.env.test` (6 matches)**: Local gitignored development/test environment files; `gitleaks git` confirmed `0` secrets across the entire git history.
2. **`gitleaks dir` — `artifacts/upgrade-u0/preserved.json` (1 match)**: SHA-256 hex file-content checksum of source code files in untracked local scratch folder.
3. **`gitleaks dir` — `frontend/.next/*` (10 matches)**: Ephemeral Next.js build preview/prerender IDs in gitignored `.next` directory.
4. **`OWASP ZAP 10055` (`CSP: script-src / style-src unsafe-inline`)**: Required by Next.js App Router hydration and Tailwind inline styles when static/dynamic routes mix; `'unsafe-eval'` is disabled in production and `frame-ancestors 'none'` + `object-src 'none'` are enforced.
5. **`OWASP ZAP 90004` (`Insufficient Site Isolation Against Spectre`)**: Informational on public booking pages (`/b/:slug`) that load static fonts/images; backend API already sends `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Resource-Policy: same-origin`.
6. **`OWASP ZAP 10116` (`ZAP is Out of Date`)**: Scanner container build timestamp warning inside pinned `ghcr.io/zaproxy/zaproxy:2.16.0` image.
